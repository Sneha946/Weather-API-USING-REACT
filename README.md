## .env.example
1. VITE_API_URL=[https://api.openweathermap.org/data/2.5/weather](http://api.openweathermap.org/data/2.5/weather)
2. VITE_API_KEY=your_api_key_here
3. VITE_HOT_URL=your_hot_image_url
4. VITE_COLD_URL=your_cold_image_url
5. VITE_RAINY_URL=your_rainy_image_url

## 🌦️ React Weather App

1. Clone the repo
2. Run `npm install`
3. Create a `.env` file from `.env.example` and add your API key
4. Run `npm run dev`
## 🛠️ Tech Stack

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Material UI (MUI)](https://mui.com/)
- [OpenWeatherMap API](https://openweathermap.org/api)
